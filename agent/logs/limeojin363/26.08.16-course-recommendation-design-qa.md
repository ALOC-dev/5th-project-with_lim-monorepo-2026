## Findings

- P0/P1/P2 차이 없음.
- 기존 앱 헤더를 유지한 것은 합의된 제품 제약이며, 카드 내부의 정보 계층·여백·라운드·색상·타임라인 정렬은 참고 화면과 일치한다.
- 실제 장소명이 참고 화면보다 길어 첫 카드와 타임라인의 세로 길이가 늘어나지만, 줄바꿈과 카드 폭은 깨지지 않는다.
- 레거시 코스는 장소별 이동 데이터가 없어 연결선만 표시되며 잘못된 `도보 0분` 문구를 만들지 않는다.
- 타임라인 연결선과 포인트는 같은 타임라인 축을 사용한다. 네 행 모두 포인트 중심과 연결선 중심의 차이가 0px임을 확인했다.
- 연결선은 현재 포인트 중심에서 다음 포인트 중심까지 그려진다. 세 구간 모두 가로 중심 오차와 다음 포인트까지의 세로 끝점 오차가 0px이다.
- 모든 버튼, 링크, 입력, 선택, 접기/펼치기 요소에 동일한 primary 500, 2px `focus-visible` 링이 적용된다.

## 필수 품질 면

- Typography: 기존 Noto Sans KR 토큰을 사용하며 제목, 본문, 메타 정보의 굵기와 크기 계층이 참고 화면과 대응한다.
- Spacing/layout: 24px 페이지 여백, 16px 카드 라운드, 16px 카드 간격과 세로 타임라인 정렬을 확인했다. 가로 오버플로는 없다.
- Colors/tokens: neutral 배경·흰 카드·primary coral 포인트만 사용한다. primary 700 텍스트의 흰색 대비는 4.83:1이다.
- Assets/icons: 새 이미지 자산은 없으며 기존 heart/chevron 아이콘만 사용한다. 지도나 임시 플레이스홀더는 남아 있지 않다.
- Copy/content: 장소 수, 총 소요 시간, 이동 시간, 비용, 경로, 추천 이유, 방문 시각과 체류 시간이 실제 API 데이터로 표시된다.

## 상호작용 및 접근성

- 추천 기록 → 결과 목록 → 첫 코스 상세 → 결과 목록 복귀 경로를 인앱 브라우저에서 확인했다.
- 뒤로 가기 44 × 44px, 상세 보기 285 × 44px 터치 영역을 확인했다.
- 코스 북마크는 장소 추천과 동일한 36 × 36px, 흰 배경, neutral 200 테두리, 24px 하트 아이콘으로 맞췄다.
- 모든 조작 요소에 접근 가능한 이름이 있고, 상세 버튼과 장소 링크에는 focus-visible 스타일이 있다.
- 공통 헤더 뒤로 가기 버튼에서도 키보드 포커스 링이 2px solid primary 500, offset 2px로 표시되는 것을 확인했다.
- 콘솔 오류는 0건이다.
- 찜 mutation은 사용자 데이터를 변경하지 않기 위해 브라우저에서 실행하지 않았으며, 기존 repository 경로와 캐시 무효화 계약을 그대로 사용한다.

## 비교 이력

1. 첫 캡처에서 개발용 React 도구가 하단 요약을 가리는 P2 검증 방해 요소를 확인했다.
2. `VITE_DISABLE_REACT_DEVTOOLS=1`로 개발 서버를 다시 실행해 오버레이를 제거했다.
3. 같은 390 × 844 뷰포트에서 다시 캡처하고, 참고 이미지와 결합해 카드·타임라인을 재검토했다. 남은 P0/P1/P2는 없다.
4. 후속 캡처에서 연결선이 포인트 왼쪽으로 치우친 정렬 회귀를 확인했다.
5. 포인트와 연결선을 하나의 타임라인 트랙에 묶고, 선을 트랙 중앙에 배치했다. 방문 시각 열은 52px로 넓히고 우측 정렬했다.
6. 390 × 844 상세 화면의 네 행에서 포인트 중심과 트랙 중심이 모두 112px, 중심 차이가 모두 0px임을 확인했다.
7. 후속 캡처에서 행 콘텐츠가 길어질 때 연결선이 다음 포인트 전에 끝나는 회귀를 확인했다.
8. 연결선을 행 내부 트랙 높이가 아닌 현재 포인트 중심부터 다음 행 포인트 중심까지 배치하고, 세 구간의 X축·끝점 오차가 모두 0px임을 확인했다.
9. 코스 기록 카드와 같은 포커스 표현을 공통 상호작용 요소에 확장하고, 키보드 탐색으로 공통 헤더 버튼의 계산 스타일을 확인했다.
