# BottomSheet / Modal Overlay 재구성

## 결론

`presence`와 `presenceAnimationDurationMs`는 page 또는 feature component의 public API가 아니다. 외부는 overlay가 열렸는지와 닫는 방법만 전달한다. mount 유지, enter/exit animation 상태, duration은 `OverlayShell` 내부 계층이 소유한다.

## 최종 API

`BottomSheet`는 아래 prop만 받는다.

```ts
type BottomSheetProps = {
  readonly id: string;
  readonly isOpen: boolean;
  readonly close: () => void;
  readonly children: React.ReactNode;
};
```

`Modal`은 기존 구조 prop을 유지하되, overlay 내부 상태 prop은 받지 않는다.

```ts
type ModalProps = {
  readonly id: string;
  readonly isOpen: boolean;
  readonly close: () => void;
  readonly title: string;
  readonly description?: string;
  readonly primaryAction: ModalAction;
  readonly secondaryAction?: ModalAction;
  readonly children?: React.ReactNode;
};
```

`useOverlay`는 page용 disclosure hook이다.

```ts
const { isOpen, open, close } = useOverlay({ initialOpen: true });
```

## 내부 상태 모델

`useOverlayPresence`는 `closed | opening | opened | closing` 상태 머신을 관리한다.

- `closed`: portal content를 렌더링하지 않는다.
- `opening`: portal content를 렌더링하고 enter animation을 실행한다.
- `opened`: 안정 상태를 유지한다.
- `closing`: portal content를 유지하고 exit animation을 실행한다.
- `closing` 중 `isOpen=true`가 되면 close timer를 취소하고 `opening`으로 되돌린다.

`isOpen` 변경은 guarded render update로 처리한다. effect는 `opening -> opened`, `closing -> closed` timer 완료만 담당한다. 이 구조는 prop과 내부 state를 effect로 동기화하는 lint 우회를 만들지 않는다.

## OverlayShell 책임

`OverlayShell`은 portal, backdrop, presence, duration CSS variable을 소유한다.

- 입력은 `id`, `isOpen`, `close`, `animationDurationMs`, `children` 중심이다.
- `useOverlayPresence`를 내부에서 호출한다.
- `closed`면 `null`을 반환한다.
- root에 `data-state={presence}`를 둔다.
- root에 `--overlay-animation-duration` CSS variable을 둔다.
- surface 컴포넌트는 descendant selector로 상태를 읽는다.

```ts
[data-state="opening"] & {
  animation: enter var(--overlay-animation-duration) ease both;
}
```

## Component 책임

`BottomSheet`는 하단 surface, 기본 handle, content padding, drag close를 소유한다. `handleType`, `zIndex`, `backdropTone`, `presence`, `duration`은 public prop으로 열지 않는다. animation duration은 내부 상수로 둔다.

`Modal`은 title, description, action row 구조를 유지한다. 단, presence와 duration은 public prop에서 제거하고 내부 motion preset으로 처리한다.

`BottomSheet`와 `Modal`은 서로 다른 surface animation을 갖는다. 공통화할 것은 presence lifecycle과 backdrop 처리뿐이다.

## 구현 순서

1. `useOverlay`를 `isOpen/open/close` disclosure hook으로 축소한다.
2. `OverlayShell`에서 `useOverlayPresence`를 호출하도록 바꾼다.
3. `OverlayShell` root에 `data-state`와 `--overlay-animation-duration`을 둔다.
4. `BottomSheetProps`에서 `OverlayProps` 상속을 제거한다.
5. `BottomSheet` surface animation을 root `data-state` selector 기반으로 바꾼다.
6. `ModalProps`에서 `OverlayProps` 상속을 제거한다.
7. `Modal` dialog animation을 root `data-state` selector 기반으로 바꾼다.
8. page 사용처에서 `presence`와 `presenceAnimationDurationMs` 전달을 제거한다.

## 테스트 기준

- `isOpen=false` 초기 상태에서는 overlay content가 렌더링되지 않는다.
- `isOpen=true`가 되면 `opening` 상태로 mount되고 duration 이후 `opened`가 된다.
- `close()` 호출 후 즉시 unmount하지 않고 `closing` 상태를 거친 뒤 `closed`가 된다.
- page는 `presence`와 `presenceAnimationDurationMs`를 import하거나 전달하지 않는다.
- `BottomSheet` consumer는 `id`, `isOpen`, `close`, `children`만 사용한다.
- `Modal` consumer는 `presence` 또는 duration을 넘기지 않는다.
